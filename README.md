# Inner Thought Landing Page

The standalone public site for **Inner Thought**, built as the sibling of
`InnerWhisperLandingPage` and designed to match the app's Info2View-inspired About
experience.

Planned public address: `https://inner-thought.movingtruth.com`

## Local preview

Serve this directory with any static web server. For example:

```bash
python3 -m http.server 8087
```

Then open `http://127.0.0.1:8087`.

## Publication boundary

The `CNAME` file is prepared, but the site must not be pushed, published, or connected
to DNS until Robin has visually tested and explicitly approved it.
